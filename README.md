# DUNE DRIFT

Браузерная 3D-игра про дрифт и гонки в открытой пустыне. Написана на Three.js (WebGL 2), без сборки: открывается как статический сайт.

## Запуск

Нужен любой локальный HTTP-сервер, потому что ES-модули не грузятся с `file://`:

```bash
python3 -m http.server 8000
# открыть http://localhost:8000
```

На GitHub Pages: Settings → Pages → Deploy from branch → корень ветки.

## Установка на телефон

Игра работает как приложение (PWA): ставится на главный экран, открывается на весь экран в горизонтальной ориентации, после первого запуска работает без интернета.

- **Android (Chrome):** кнопка «УСТАНОВИТЬ НА ТЕЛЕФОН» в меню, либо ⋮ → «Добавить на главный экран».
- **iPhone (Safari):** «Поделиться» → «На экран „Домой“».

## Стиль управления

Кнопка «СТИЛЬ» (или клавиша V) переключает:
- **АРКАДА** — устойчивая машина, заносы на ручнике и в резких поворотах.
- **ДРИФТ** — почти задний привод, скользкая корма: газ и руль срывают в занос, можно ехать боком до 90° и крутиться на 360°. Отпустите руль — машина выровняется.

В обоих стилях:
- **«Пончик»**: газ + полный руль на месте (в аркаде ещё и ручник) — машина крутится вокруг себя.
- **Вращение в прыжке**: держите руль в полёте — 360° с обычного прыжка, 720° и больше с трамплина. За вращение дают очки.
- **Задом наперёд**: после разворота на 180° машина ещё несколько секунд катится задом, колёса буксуют.

## Графика

В меню четыре пресета: **ПК (макс.)** (по умолчанию на всех устройствах — та же картинка, что на компьютере), **Высокое**, **Среднее**, **Низкое**. Галочка «Снижать разрешение, если тормозит» включает автоподстройку разрешения под 60 FPS. Выбор запоминается.

## Что внутри

**Мир**
- Процедурная пустыня 1.6 × 1.6 км. Асимметричные барханы (пологий наветренный склон и крутой подветренный) с гребнями, с которых машина взлетает.
- Замкнутая трасса из Catmull-Rom сплайна, вписанная в рельеф: укатанная колея, обочины, вешки, стопки покрышек на поворотах, стартовые ворота.
- Лагерь в центре: алюминиевые трейлеры, контейнеры, сарай, ветряк, водонапорная башня, цистерна. По миру разбросаны ещё 11 стоянок.
- Две линии ЛЭП с провисающими проводами, скальные гряды, сухие деревья, кусты, которые качаются на ветру, перекати-поле.
- Разрушаемые заборы, бочки и покрышки: от удара разлетаются с физикой.
- Деревянные трамплины на трассе и по всей карте.
- Дрифт-чаша: огромная воронка с забором, покрышками и прожекторами — для кругов и восьмёрок.
- Оазис с прудом (анимированная вода), пальмами, тростником и шатром.
- Брошенные ржавые машины, старые автобусы, заброшенная заправка, радиовышки с мигающими огнями, столовые горы по краям карты, кактусы, ломаемые ящики, указатели.

**Шейдеры и графика**
- Песок (`src/shaders/sand.js`): рябь от ветра с двумя масштабами волн, бегущие полосы сдуваемого песка, блёстки кварца на солнце, вариации цвета по склонам и высоте.
- Следы шин рисуются в мировую render target с MAX-смешиванием. Из неё шейдер песка берёт и цвет, и рельеф колеи (bump). Следы остаются на всю сессию.
- Пыль, шлейфы в заносе, «петушиный хвост» песка, дым шин на трассе, пламя импульса. Это инстансированные билборды с процедурным объёмным освещением от солнца.
- Небо: градиент, солнце с ореолом, перистые облака, дымка у горизонта. Из него же строится PMREM-карта окружения для отражений лака, хрома и стекла.
- Постобработка: MSAA, Unreal Bloom, ACES. Затем свой проход: марево от жары, радиальное размытие и хроматическая аберрация на импульсе, цветокоррекция, виньетка, зерно.
- Мягкие тени, которые следуют за машиной (со снапом к текселю). Два времени суток: день и закат.

**Физика машины** (`src/car.js`)
- «Велосипедная» модель шин с кривой Пасейки, перенос веса, фрикционный круг: на газу задняя ось теряет сцепление.
- Ручник, контрруление, аркадная помощь в заносе, разное сцепление на трассе и на рыхлом песке.
- Отрыв на гребнях и трамплинах, прыжок, приземление с ударом подвески. Визуальная подвеска колёс и крены кузова.

**Игра**
- Очки за дрифт с множителем, бонусы за полёты и разнос препятствий. Заносы заряжают импульс.
- Режим «НА ТРАССУ»: отсчёт, 12 чекпоинтов с анимированными арками и световым столбом, круги, лучший круг (сохраняется), позиция среди трёх ботов.
- Боты ездят по трассе, срезают в заносе, пылят и прыгают с трамплинов.
- Синтезированный звук на WebAudio: двигатель с передачами, шорох песка, визг шин, ветер, удары, турбо.
- Динамическое разрешение, чтобы держать около 60 FPS. На телефонах облегчённые настройки.

## Управление

| Клавиатура | Действие |
|---|---|
| W / ↑ | газ |
| S / ↓ | тормоз, задний ход |
| A D / ← → | руль |
| Пробел | ручник |
| Shift | импульс |
| J | прыжок |
| C | камера (высокая / погоня / дрон / капот) |
| T | на трассу / свободная езда |
| N | день / закат |
| R | вернуть машину на колёса |
| M | звук |
| Мышь (тянуть) | обзор вокруг машины |

Геймпад: стик — руль, RT/LT — газ и тормоз, A/RB — ручник, X/LB — импульс, Y — прыжок, B — камера.

На телефоне управление как в видео-референсе. Слева слайдер руля: свайп вверх — прыжок, свайп вниз — импульс. Справа газ, тормоз, ручник, импульс и прыжок.

```

lib/three/                 Three.js r169 и нужные аддоны (локально, без CDN)
src/main.js                сборка сцены, игровой цикл, события
src/config.js              размер мира и качество графики
src/noise.js               simplex-шум и утилиты
src/track.js               генерация трассы
src/terrain.js             рельеф, высоты для физики, материал песка
src/shaders/sand.js        GLSL песка
src/tiretracks.js          следы шин (render target)
src/sky.js                 небо
src/world.js               объекты мира, столкновения, разрушаемые предметы
src/car.js, carModel.js    физика и модель машины
src/ai.js                  боты
src/particles.js           система частиц
src/effects.js             эмиттеры пыли, следов, дыма
src/cameraRig.js           камеры
src/post.js                постобработка
src/race.js                гонка и очки дрифта
src/input.js               клавиатура, геймпад, сенсор
src/audio.js               звук
src/hud.js                 интерфейс и миникарта
```
